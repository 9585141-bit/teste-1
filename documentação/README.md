# 📚 Documentação

Área para procedimentos técnicos, checklists, padrões de trabalho, notas de estudo e evolução do laboratório.

## Regra de documentação

Documentar antes, durante e depois das reparações importantes.

Não publicar dados pessoais de clientes, códigos de desbloqueio, IMEI/serial associados a pessoas ou fotografias identificáveis.
