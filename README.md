**Versão:** 1.0 — Planeamento inicial

---

## 🎯 Objetivo

Criar um processo profissional para receção, diagnóstico, orçamento, reparação, testes e entrega de telemóveis e equipamentos eletrónicos.

O projeto começa pela organização dos processos e, numa fase posterior, poderá integrar software, automação e o ecossistema BITY JR.

---

# 🧪 TESTE 1 — Receção e Triagem do Telemóvel

### Objetivo

Criar uma ficha inicial para registar o aparelho antes de qualquer reparação.

### 1. Identificação do aparelho

- Marca
- Modelo
- IMEI, quando disponível
- Número de série, quando disponível
- Data de entrada
- Número da ficha de serviço

### 2. Estado exterior

Verificar e registar:

- ☐ Ecrã intacto
- ☐ Ecrã partido
- ☐ Tampa traseira intacta
- ☐ Tampa traseira danificada
- ☐ Estrutura/moldura danificada
- ☐ Sinais de queda
- ☐ Sinais de humidade/água
- ☐ Parafusos ou peças em falta

### 3. Sintoma informado pelo cliente

Registar exatamente o problema relatado pelo cliente, sem assumir ainda a causa.

**Exemplo:**

> "O telemóvel não carrega."

### 4. Testes básicos de entrada

Antes de abrir o aparelho, verificar quando for seguro fazê-lo:

- ☐ Liga/desliga
- ☐ Ecrã apresenta imagem
- ☐ Touch responde
- ☐ Carregamento funciona
- ☐ Botões funcionam
- ☐ Câmara funciona
- ☐ Microfone funciona
- ☐ Altifalante funciona
- ☐ Rede móvel/SIM
- ☐ Wi-Fi
- ☐ Bluetooth

## Regra do projeto

> **Não confundir sintoma com diagnóstico.**
>
> O cliente informa o sintoma. O técnico realiza os testes e determina as possíveis causas.
